# Medical Appointment Booking

## Project Overview
Medical Appointment Booking is a website designed to help users book medical appointments.

## Features
- Browse available medical services.
- Book medical appointments.
- View information related to appointments.

## General Instructions
- Use a modern web browser to access the website.
- Follow the instructions provided on the website when booking an appointment.
- Ensure that all required information is entered correctly.

## Notes
This project is part of a front-end development capstone project.
